# Maintainer skills

This directory contains development playbooks for assistants/agents and human maintainers.

- `architecture` — understand boundaries and modules
- `add-strategy` — implement a custom selection strategy
- `resilience` — health checks, recovery, retries, circuit breakers
- `performance-optimization` — performance regression workflow
- `testing` — unit/integration/failure testing
- `add-adapter` — Express/Fastify/protocol integration rules
- `security-review` — threats and review checklist
- `release` — npm release process

Read `AGENTS.md` first and do not claim unsupported capabilities.

- `proxy-review/`: HTTP stream lifecycle, header security, retry safety.
- `integration-tests/`: real-socket test design and cleanup conventions.
